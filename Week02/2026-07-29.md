## 오늘 배운 내용

#### 📌 Agent 주도 개발을 위한 환경 설정하기

Agent 주도 개발을 위한 환경 설정을 진행했다. 토큰 사용량을 줄이기 위한 여러 커넥터, 스킬 등을 알게 되었다. 하나씩 적용해보고 실제로 얼마나 사용량 감소가 체감되는지 확인해보려고 한다.
이외에도 IDE에서 ADE인 Orca를 세팅했다. 기존 VSCode에서는 여러 프로젝트나 여러 브랜치를 오가며 작업할 때 매번 변경사항을 커밋하거나 스태시하고 이동해야 해서 번거로웠는데, Orca는 git worktree 방식으로 로컬 저장소 자체를 복제하기 때문에 그런 번거로움을 줄일 수 있다.
실제로 사용해보니 터미널을 여러 개 띄우고 작업할 수 있다는 점, 코드 에디팅이 가능하다는 점, 에이전트와의 대화 세션을 기준으로 작업 환경의 전환이 가능하다는 점이 좋았다. 반면 아무래도 에디터는 아니다보니 파일을 불러오고 편집하는 게 조금 느리다는 점은 아쉬웠다.
앞으로 강의를 통해 Orca 등의 편집기에서 Codex, Claude Code 등 여러 에이전트에게 서로 검증을 시키는 방식 등을 배울 수 있다고 하니 코드 리뷰나 기술 검토에 적용해 보면 좋을 것 같다.

#### 📌 Claude를 활용한 교육 과정 아침 & 저녁 루틴 설계하기

Claude를 활용해 아침과 저녁 루틴을 설계했다.
매일 아침 뭐라도 더 해 보려고 30분 일찍 출근하고 있는데, 막상 출근하면 뭘 해야 하는지 뇌정지가 오는 경우가 많았다.
저녁에는 TIL을 작성하고 있지만 그래도 내가 오늘 배운 내용을 다 소화하기에 TIL로는 조금 부족하다는 생각이 들었고, 좀 더 생산성을 향상시키고 내가 오늘 한 작업들을 나의 실제 자산으로 남길 수 있으면 좋겠다는 생각이 들었다.
그래서 아침과 저녁 루틴을 Claude를 활용해 직접 설계하고 적용해보았고, 특히 저녁 루틴의 경우 옵시디언과 LLM 위키의 개념을 차용해 오늘 에이전트와 나눈 대화 내용을 저장하고 TIL로 남길 수 있도록 Codex 루틴을 만들어 매일 교육 종료 30분 전에 실행되도록 했다.
오늘 한번 시범적으로 TIL 루틴을 사용해봤는데 정말 좋은 것 같다. 오늘 했던 일들이 요약된 핵심 내용은 클로드가 요약해주고, 나는 요약을 읽고 복기하면서 다 내 것으로 소화만 시키면 된다. 대화 내용을 하나씩 찾아보면서 '아 나 오늘 뭐 했더라' 하는 데 드는 시간을 최소화할 수 있었다.
