## 오늘 배운 내용

#### 📌 공유회를 위한 조별 과제 진행

오늘은 공유회를 위한 조별 과제를 진행했다. (오늘 만든 결과물은 Github Pages로 웹에 띄워보려고 한다.) 별도의 개별 과제는 없어서 하루 종일 조별 과제를 열심히 했다… 다른 분들의 결과물들을 보며 내 부족한 부분을 많이 느낄 수 있었다. 막막하다고 대충 시키는 게 아니라, 좋은 프롬프트가 뭔지 생각하면서 좋게 작성하기 위해 노력해야 좋은 결과물을 얻을 수 있다.

#### 📌 디자인 작업은 토큰이 많이 든다

별 디자인 작업 시키지도 않은 것 같은데, 디자인만 시켰다 하면 토큰을 다 써버려서 힘들었다. 심지어 디자인은 그렇게 괜찮지도 않다. 나름 디자인을 잘 하는 편이라고 생각했는데, 클로드를 시켜서 디자인을 하려니까 내 맘처럼 잘 되지 않는 것 같다.

## 더 알아보고 싶은 것

#### ❓ 내가 원하는 디자인을 프롬프트만으로 뽑아내는 방법

클로드를 시켜서 내가 원하는 디자인을 프롬프트만으로 뽑아내는 효과적인 방법에 대해 좀 더 찾아봐야겠다. 혼자서 작업을 하다 보면 결국 디자인도 직접 해야 하는 경우가 많은데, 그럴 때마다 이렇게 디자인 작업에 시간을 오래 쓰고, 그렇다고 결과물이 좋지도 않으면 너무 효율이 떨어질 것 같다. 내가 원하는 디자인을 프롬프트만으로 뽑아내는 방법을 좀 더 찾아보고 적용해봐야겠다.
