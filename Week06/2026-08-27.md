## 새롭게 알게된 것

#### 🗣 자기 개선 하네스

[자기 개선 하네스](https://news.hada.io/topic?id=32861)에 대해 알게 됐다. 단발성 대화가 아닌, 며칠씩 이어지는 장기 자율 작업을 지속시키는 데 집중한 에이전트 프레임워크라고 한다. RLM 방식, Continual 하네스 방식을 사용하는 에이전트라고 하는데, 두 방식에 대해서도 잘 몰라서 좀 더 찾아봐야 할 것 같다. 지금으로서는 장기적인 작업에 사용할 수 있는 스스로를 개선하는 하네스 정도로 이해하고 있다.

#### 🗣 vLLM

[vLLM](https://vllm.ai/)은 LLM의 추론과 서빙을 효과적으로 수행하기 위해 개발된 오픈소스이다. 기존 LLM 추론 시스템은 메모리의 비효율성과 낮은 처리량으로 인해 GPU 메모리를 과도하게 소모하고 충분한 요청을 처리하지 못하는 문제가 있었다. 이로 인해 API 서비스 형태로 제공 시 빠른 응답 속도와 높은 처리량을 동시에 만족시키기 어렵다는 한계가 있었는데, 이를 해결하기 위해 PagedAttention 기술을 도입해 연산을 메모리 페이지 단위로 관리한다. 이를 통해 메모리 공간을 더욱 효율적으로 사용할 수 있다. 현재는 LLM 환경에서 거의 표준으로 인식되고 있다고 한다. 이런 게 있다 정도만 알아두고 넘어가자.
