## 오늘 배운 내용

#### 📌 LLM API는 검증된 Provider를 사용하자

클로드들이 추천한 DeepInfra라는 LLM 호스팅 서비스에서 gpt-oss-120b 모델을 써 봤다. Groq 유료 결제가 막혀 있어서 대안으로 에이전트들이 추천해줘서 일단 5달러 넣고 테스트를 돌려 봤는데 Groq보다 응답 속도가 4배 느렸다. 내 피같은 돈… 중국 회사 아닌 것만 확인하고 냅다 5달러 지른 게 문제였던 것 같다. 좀 찾아보고 결제할 걸… 앞으로 LLM API나 호스팅 서비스는 좀 찾아보고 어느 정도 검증된 경우에만 결제하자.

#### 📌 이력서 개선은 끝이 없다

당근 지원을 위해 이력서 개선안을 세웠다. 생각보다 반영하고 고칠 게 너무 많다. 그리고 JD를 읽으면서 es-toolkit, ts-pattern, 함수형 프로그래밍 등 에이전트가 좋은 코드를 쉽게 작성할 수 있는 하네스에 대해서도 알게 되었다. 그동안은 업무 방식이나 워크플로우에만 하네스를 적용했었는데, 코드에도 하네스를 적용한다면 일관된 품질의 코드를 작성하도록 강제할 수 있을 것 같다. 좀 더 찾아보고 내 프로젝트에 반영해보고 싶다.

## 더 알아보고 싶은 것

#### ❓ 엔비디아 무료 LLM 모델 사용해보기

오늘 LLM API를 테스트하고 관련해서 대화를 나누다가 엔비디아에서 제공하는 무료 LLM 모델 [nemotron](https://build.nvidia.com/nvidia/nemotron-3-ultra-550b-a55b)에 대해 알게 되었다. 사용 방법은 더 찾아봐야겠지만 무료 모델인 만큼 개발 시에나 테스트 시에 적극적으로 활용해보면 좋을 것 같다.
