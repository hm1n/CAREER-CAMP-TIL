# CAREER-CAMP-TIL
AI Native Career Camp에서 배우고 느낀 점들을 매일 기록합니다.

## 폴더 규칙

- 캠프 시작일: 2026-07-22 (1주차 1일째)
- 주차 단위로 폴더를 나눕니다: `WeekNN/`
- 폴더 안에는 날짜만으로 된 파일을 만듭니다: `YYYY-MM-DD.md`
- 제목은 파일 내부 첫 줄(`# 제목`)에 적습니다.
- 이미지/첨부파일은 다루지 않습니다.

```
CAREER-CAMP-TIL/
├── README.md
├── Week01/
│   ├── 2026-07-22.md
│   └── ...
├── Week02/
│   ├── 2026-07-27.md
│   └── ...
```
