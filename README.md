## TIL 작성 형식

모든 기록은 같은 틀로 썼습니다. 날짜에 따라 빠지거나 더해진 섹션도 있습니다.

| 섹션 | 아이콘 | 내용 |
|---|---|---|
| 오늘 배운 내용 | 📌 | 그날 새로 배우거나 직접 해 본 것 |
| 새롭게 알게된 것 | 🗣 | 협업과 프로젝트를 하며 깨달은 것 |
| 더 알아보고 싶은 것 | ❓ | 아직 답을 찾지 못한 질문과 공부할 거리 |
| 나에게 적용한다면 | 💡 | 내 작업 방식에 바로 가져갈 행동 |
| 한 줄 회고 | > | 하루를 마무리하는 한 문장 |

```markdown
# YYYY-MM-DD

## 오늘 배운 내용

#### 📌 오늘의 주제

본문

## 더 알아보고 싶은 것

#### ❓ 궁금한 점

## 나에게 적용한다면

#### 💡 바로 해 볼 행동

## 한 줄 회고

> 하루를 마무리하는 한 문장
```

## 폴더 규칙

- 캠프 시작일인 2026-07-22를 1주차 첫날로 봅니다.
- 캠프는 평일에만 열렸고, 새 주차는 월요일에 시작합니다.
- 주차마다 `WeekNN/` 폴더를 만들고, 그 안에 `YYYY-MM-DD.md` 파일을 둡니다.
- 파일 첫 줄에는 `# YYYY-MM-DD` 형식으로 날짜를 적습니다.
- 이미지와 첨부파일은 올리지 않습니다.

```
CAREER-CAMP-TIL/
├── README.md
├── Week01/
│   ├── 2026-07-22.md
│   └── ...
├── ...
└── Week17/
    ├── 2026-11-09.md
    └── ...
```

## 기록 방식

1. 하루가 끝나면 노션 TIL 데이터베이스에 그날의 기록을 씁니다.
2. Claude Code의 `notion-til-upload` 스킬로 노션 페이지를 마크다운 파일로 바꿉니다.
3. 주차 폴더에 파일을 넣고 `YYYY-MM-DD TIL 업로드` 메시지로 하루에 커밋 하나씩 올립니다.

자세한 변환 규칙은 [SKILL.md](.claude/skills/notion-til-upload/SKILL.md)에 적어 두었습니다.

README는 [jbranchaud/til](https://github.com/jbranchaud/til)과 [simonw/til](https://github.com/simonw/til)을 참고해서 만들었습니다.
