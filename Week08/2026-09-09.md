#### ❓ AI 서비스의 BM

API 사용량에 대해 고민을 안 할 수가 없는데, 한 경험 블록 대화 10턴 당 150원에서 200원 정도가 소모된다. 내 생각보다 엄청 큰 금액이라 놀랐다… 어쨌든 API 사용에 돈이 드는 만큼 BM을 고민 안 할 수가 없는데, 어떤 식으로 BM을 만들면 좋을 지도 고민해 보고 결제 기능도 붙일 수 있다면 붙여봐야겠다.
